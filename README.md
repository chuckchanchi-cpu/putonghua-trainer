# 🗣️ 普通話拼音訓練器

普通話拼音訓練 Streamlit app — 拼音詞語／聲調／易錯音／拼寫規則／韻母辨析，各 Section 獨立揀、獨立練。

## 題庫（教材原題，100% 嚟自教材）

1. 拼音詞語・第1課《我的新居》— 7 詞
2. 拼音詞語・第2課《邀約》— 5 詞
3. 拼音詞語・第3課《升中面試》— 8 詞
4. 拼音詞語・第4課《運動會》— 9 詞
5. 易錯音辨析（平翹舌・前後鼻・多音字）— 10 題
6. 拼寫規則（人名・地名・專有名詞）— 10 題
7. 韻母辨析（前後鼻・iang/uang・in/uen/un）— 10 題

共 59 題教材原題。

## 兩個生成模式

- **📖 教材原題**：即時、100% 教材題目
- **✨ AI 生成新題**：根據教材規則（拼音詞語／聲調／拼寫規則／韻母辨析）生成新題，答案必須原字照抄選項

## 部署

Streamlit Cloud 揀呢個 repo，Main file = app.py。API key 設喺 Secrets（OPENAI_API_KEY）。
